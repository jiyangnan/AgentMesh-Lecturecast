Lecturecast はAgentMesh360 の商用講座動画製品です。AI エージェントが有効な月間パスと共通 API キーを検証し、クラウド Director が構造化された選択を署名付き制作計画と脚本へ変換します。あなたのマシンは2 本の MP4 と対応する 2 枚のカバーを制作します。元素材はアップロードされず、ナレーション本文だけが選択した TTS サービスへ送られます。 （B 站と小红书は中国の主要動画プラットフォーム——それぞれ横向き／縦向き）。利用しない場合でも、両フォーマットが揃って出力されます。）

なぜ任せるのか

脚本は AI に書かせられても、成片の作業が本当の難題です。

AI に脚本を書かせるのは難しくありません。難しいのはその後——配音、タイムライン整合、レンダリング、字幕焼き付け、カバー作成、横版と縦版それぞれの調整です。

Lecturecast は AI エージェントに実行可能な唯一の制御フローを渡します。Director が署名済み制作計画を、本機が TTS・時間軸・レンダリングを担当します。権限、素材、時間、QA のいずれかが失敗した場合、納品はその場で停止し、完成したように見えるテキストや不完全な動画は届けられません。

機能 · クラウドで計画、ローカルで制作

一つのテーマから、2 本の成片へ。

i.

Director の署名付き脚本

Creative Brief で方向と事実を確認します。10 credits の承認後、Director は変更不可の署名付き ProductionManifest と署名脚本全文を生成し、宿主 Agent による書き換えは不可です。

ii.

ローカル配音と整合

署名脚本の全文承認後だけ TTS を実行します。実測音声がシーン・字幕・動画尺を駆動し、各節または合計が 75–125% の安全範囲を外れるか、最終 A/V 差が 1 秒を超えるとビルドは停止します。

iii.

2 プラットフォーム同時レンダリング

同じ脚本から、ローカルの Remotion で B 站横版（16:9）と小红书縦版（9:16）を一度に出力。それぞれにレイアウトが最適化され、後から再編集する必要はありません。

iv.

字幕 + カバー

ローカル ffmpeg が中国語字幕を焼き付け、対応する 2 枚の PNG カバーを生成します。完全デコード、音声範囲、字幕字形、寸法 QA を通過してから人間の最終確認へ渡します。

ローカル 3 点セット依存

すべてあなたのマシン上で。

macOS と Windows をネイティブ対応し、Linux / WSL は非対応です。クラウドのメディア worker もリモートレンダラもありません。クラウドは商用アクセス、制作判断、署名 Manifest を担当し、ナレーション本文は選択した TTS サービスへ送られます。install.sh / install.ps1 がローカル環境の不足を確認します。

RENDER

Node + Remotion

コード駆動のアニメシーンで 2 アスペクト比をレンダリング。Node 20+ を入れ、npm install でプロジェクトを準備します。

VOICE

Python + edge-tts

音声ファイルはローカルで生成・保存。クライアントはナレーション本文を Microsoft Edge 音声サービスへ送り、MiniMax BYOK では署名脚本本文を自分の MiniMax アカウントへ送ります。

MUX

ffmpeg（libass 付き）

中国語字幕を焼き付け、成片を合成。macOS は ffmpeg-full、Windows は libass 入りネイティブ ffmpeg build を使い、doctor が実際の能力を検証します。

使い方

エージェント向けに設計。

インストール済み Skill が唯一の制御フローを駆動します。Brief、10-credit Manifest 生成、署名脚本全文は 3 つの独立した人間承認ゲートです。

01

CLI をインストール

macOS は install.sh、Windows PowerShell は install.ps1 を使用します。どちらも商用 CLI、署名検証、宿主 Agent Skill を導入します。完了後は新しい Agent タスクを開始し、Skill の正確な --adapter と --host-contract で onboard します。

02

エージェントが商用 onboarding を完了

新しいタスクがインストーラー所有の最新 Skill を証明し、アカウント、月間パス、credits、レンダラを確認します。その後は CLI が返す唯一の workflow.next_action だけを実行します。Skill 不足や宿主 drift は書き込み前に停止します。
AGENTS.md を見る →

03

Director が計画し、本機が制作

Director の選択と Brief 承認を経て、10 credits を消費して署名付き ProductionManifest を取得します。Agent は変更不可の署名脚本全文を提示し、改めて承認を待機します。承認後に限り、ローカルで TTS、縦横両バージョンのレンダリング、字幕、2 枚のカバーを実行し、QA が失敗した場合は納品を停止します。

よくある質問

FAQ.

有料ですか？アカウント登録は必要？
Lecturecast には有効な AgentMesh360 月間パスと共通 API キーが必要です。月間パスの共有 credits を使い、LectureCast 専用契約は不要です。選択と Brief は無料で、10 credits は ProductionManifest 生成の承認時にのみ消費されます。
動画はクラウドにアップロードされますか？
元素材はアップロードされません。限定された素材要約、安定した選択肢 ID、Brief、クライアント能力はクラウド Director へ、ナレーション本文は選択した TTS サービスへ送られます。元素材、ローカルパス、生成音声、字幕、レンダリング、完成品はローカルに残ります。
配音は何を使いますか？もっと良い声に変えられますか？
Edge TTS はナレーション本文を Microsoft Edge 音声サービスへ送ります。MiniMax BYOK は署名脚本本文を自分の MiniMax アカウントへ送ります。LectureCast は MINIMAX_API_KEY を意図的に永続化しません。安全なプロセス環境注入を推奨し、shell に直接 export すると履歴に残る場合があります。
完全自動ですか？人間の承認ゲートは？
無人運用ではありません。納品には 3 つの人による承認（Creative Brief、10 credits による Manifest 生成、署名脚本全文の段階的な確認）が必要です。署名後の内容は宿主 Agent が変更できず、いずれかの承認ゲートを通過しない場合は TTS やレンダリングに進まず、納品は停止されます。
何をインストールする必要がありますか？
ローカル 3 点セットは Node + Remotion、Python + edge-tts、libass 入り ffmpeg。macOS の install.sh と Windows の install.ps1 は CLI 導入とレンダラ準備を区別し、doctor が能力を判定します。
どのプラットフォーム向けの成片に対応していますか？
標準 4 ファイル：B 站横版 MP4（1920×1080）、小红书縦版 MP4（1080×1920）、対応する 2 枚の PNG カバー。
公開クライアントはオープンソースですか？
公開 CLI、ローカル実行ツール、サイトは GitHub で Apache 2.0 です。完全な製品経路は一つだけで、有効な月間パス、共通 API キー、共有 credits、クラウド Director が必須です。アカウント不要の経路はありません。
