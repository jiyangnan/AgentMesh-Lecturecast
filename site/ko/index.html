하나의 아이디어를, 강의 영상 한 편으로.

Lecturecast 는 AgentMesh360 상용 강의 영상 제품입니다. AI 에이전트가 유효한 월간 패스와 범용 API 키를 검증하고 클라우드 Director 가 구조화된 선택을 서명된 제작 계획과 대본으로 바꿉니다. 당신의 머신은 MP4 두 편과 각각의 커버 두 장을 제작합니다. 원본 미디어는 업로드되지 않으며 내레이션 텍스트만 선택한 TTS 서비스로 전송됩니다. (Bilibili 와 Xiaohongshu 는 중국의 주요 영상 플랫폼—각각 가로판/세로판. 사용하지 않더라도 두 포맷을 함께 출력합니다.)

클라우드 디렉팅, 로컬 제작.

에이전트는 범용 API 키, 유효한 월간 패스, 공유 credits 를 먼저 검증하고 네이티브 선택 UI 와 Brief 승인을 마칩니다. 10 credits 차감이 확인되면 클라우드 Director 가 서명된 ProductionManifest 와 전체 서명 대본을 생성하며, 두 항목은 호스트 Agent 가 임의로 수정할 수 없습니다. 전체 서명 대본은 구간별로 사람의 승인을 거쳐야만 로컬 TTS 와 렌더링으로 진행합니다.

왜 맡겨야 하는가

대본은 AI 에게 맡길 수 있어도, 제작이 진짜 고통입니다.

AI 에게 대본을 쓰게 하는 건 어렵지 않습니다. 어려운 건 그 뒤—더빙, 타임라인 정렬, 렌더링, 자막 굽기, 커버 작업, 그리고 가로판과 세로판을 매번 따로 맞추는 일입니다.

Lecturecast 는 AI 에이전트에 실행 가능한 단일 제어 흐름을 제공합니다. Director 는 서명된 제작 계획을, 로컬 머신은 TTS·타이밍·렌더링을 담당합니다. 권한, 자산, 타이밍, QA 검사 중 하나라도 실패하면 납품이 중단되며, 완성된 듯한 텍스트나 불완전한 영상은 전달되지 않습니다.

기능 · 클라우드 계획, 로컬 제작

하나의 주제에서 두 편의 영상으로.

i.

Director 의 서명된 대본

Creative Brief 에서 방향과 사실을 확인합니다. 10 credits 승인 후 Director 가 변경 불가능한 서명 ProductionManifest 와 전체 대본을 생성하며, 호스트 Agent 는 이를 임의로 수정할 수 없습니다.

ii.

로컬 더빙과 정렬

서명 대본 전체를 승인한 뒤에만 TTS 를 실행합니다. 실측 오디오가 장면·자막·영상 길이를 구동하며, 각 섹션이나 전체가 75–125% 안전 범위를 벗어나거나 최종 A/V 차이가 1초를 넘으면 빌드를 중단합니다.

iii.

이중 플랫폼 렌더링

같은 대본을 로컬 Remotion 으로 Bilibili 가로판(16:9)과 Xiaohongshu 세로판(9:16)으로 한 번에 출력합니다. 각각의 레이아웃에 최적화되어, 다시 편집할 필요가 없습니다.

iv.

자막 + 커버

로컬 ffmpeg 가 중국어 자막을 굽고 각각의 PNG 커버 두 장을 생성합니다. 전체 디코드, 오디오 커버리지, 자막 글리프, 해상도 QA 를 통과한 뒤 사람의 최종 검토로 전달합니다.

로컬 3 가지 세트

모두 당신의 머신에서.

macOS 와 Windows 를 네이티브 지원하며 Linux / WSL 은 지원하지 않습니다. 클라우드 미디어 워커나 원격 렌더러는 없습니다. 클라우드는 상용 접근, 창작 결정, 서명 Manifest 를 담당하고 내레이션 텍스트는 선택한 TTS 서비스로 전송됩니다. install.sh / install.ps1 가 로컬 환경의 누락 항목을 확인합니다.

RENDER

Node + Remotion

코드 기반 애니메이션으로 두 비율을 렌더링합니다. Node 20+ 설치 후 npm install 로 프로젝트를 준비합니다.

VOICE

Python + edge-tts

오디오 파일은 로컬에서 생성·저장됩니다. 클라이언트는 내레이션 텍스트를 Microsoft Edge 음성 서비스로 보내며 MiniMax BYOK 는 서명 대본 텍스트를 본인의 MiniMax 계정으로 보냅니다.

MUX

ffmpeg(libass 포함)

중국어 자막을 굽고 최종 영상을 합성합니다. macOS 는 ffmpeg-full, Windows 는 libass 포함 네이티브 ffmpeg build 를 사용하며 doctor 가 실제 기능을 검증합니다.

사용법

에이전트 친화적으로 설계.

설치된 Skill 이 하나의 제어 흐름을 구동합니다. Brief 승인, 10-credit Manifest 생성 승인, 전체 서명 대본 승인은 서로 독립된 세 번의 사람 게이트입니다.

자주 묻는 질문

FAQ.

유료인가요? 계정 가입이 필요한가요?
Lecturecast 는 유효한 AgentMesh360 월간 패스와 범용 API 키가 필요합니다. 월간 패스 계정의 공유 credits 를 사용하며 별도 LectureCast 구독은 필요 없습니다. 선택과 Brief 는 무료이고 10 credits는 ProductionManifest 생성 승인 시에만 차감됩니다.
영상이 클라우드로 업로드되나요?
원본 미디어는 업로드되지 않습니다. 제한된 소스 요약, 안정적인 선택 ID, Brief, 클라이언트 기능은 클라우드 Director 로 가고 내레이션 텍스트는 선택한 TTS 서비스로 갑니다. 원본 미디어, 로컬 경로, 생성 오디오, 자막, 렌더링, 완성본은 로컬에 남습니다.
더빙은 무엇을 쓰나요? 더 좋은 음색으로 바꿀 수 있나요?
Edge TTS 는 내레이션 텍스트를 Microsoft Edge 음성 서비스로 보냅니다. MiniMax BYOK 는 서명 대본 텍스트를 본인의 MiniMax 계정으로 보냅니다. LectureCast 는 MINIMAX_API_KEY 를 의도적으로 영구 저장하지 않습니다. 안전한 프로세스 환경 주입을 권장하며 shell 에 직접 export 하면 기록에 남을 수 있습니다.
완전 자동인가요? 사람 승인 게이트는 무엇인가요?
무인 실행이 아닙니다. 납품에는 Creative Brief, 10 credits Manifest 생성, 전체 서명 대본의 구간별 검토라는 세 번의 사람 승인이 필요합니다. 서명 후 호스트 Agent 는 내용을 수정할 수 없으며, 한 단계라도 통과하지 못하면 TTS 나 렌더링으로 진입하지 않고 중단됩니다.
무엇을 설치해야 하나요?
로컬 3 가지 세트는 Node + Remotion, Python + edge-tts, libass 포함 ffmpeg 입니다. macOS install.sh 와 Windows install.ps1 은 CLI 설치와 렌더러 준비를 구분하며 doctor 가 기능을 판정합니다.
어떤 플랫폼용 영상에 대응하나요?
표준 네 파일: Bilibili 가로 MP4(1920×1080), Xiaohongshu 세로 MP4(1080×1920), 그리고 각각에 맞는 PNG 커버 두 장.
공개 클라이언트는 오픈소스인가요?
공개 CLI, 로컬 실행 도구, 사이트는 GitHub 에서 Apache 2.0 입니다. 완전한 제품 경로는 하나뿐이며 유효한 월간 패스, 범용 API 키, 공유 credits, 클라우드 Director 가 필수입니다. 계정 없는 경로는 없습니다.
