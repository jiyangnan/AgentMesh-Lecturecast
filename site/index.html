COMMERCIAL ACCESS · LOCAL PRODUCTION

把一个想法，变成一条课程视频。

Lecturecast 是 AgentMesh360 的商业课程视频产品：用户 Agent 先验证有效月卡与通用 API Key，由云端 Director 把结构化创作选择变成签名制作方案和讲稿，再在你的机器上完成配音、编辑和渲染，同时产出横版与竖版 MP4 及两张封面。原始媒体不上云；旁白文本会发送给你选择的 TTS 服务。

为什么不自己剪

写稿能交给 AI，出片才是真麻烦。

让 AI 写个脚本不难，难的是后面——配音、对轴、渲染、烧字幕、做封面、还要横竖两版各适配一次。

Lecturecast 把可执行控制流交给你的 AI agent：Director 负责签名创作方案，本机负责 TTS、时间线和渲染。任何权限、素材、时长或 QA 检查失败都会停止交付，而不是给你一段看似完成的文字或残缺视频。

产品能力 · 云端定方案，本机制作

从一句主题，到两条成片。

i.

Director 生成签名讲稿

你先在 Creative Brief 中确认方向与事实；批准 10 credits 后，Director 生成不可变的签名 ProductionManifest 与完整讲稿。宿主 Agent 不能擅自改写。

ii.

本地配音对轴

完整签名讲稿经你逐段批准后才进入 TTS。真实音频时长驱动场景、字幕和成片时长；任一分节或总时长超出 75–125% 安全范围，或音视频覆盖差超过 1 秒，构建会停止。

iii.

数字人出镜

可选照片数字人：上传一张照片，由云端 Director 签发制作方案，你的 HeyGen API Key 处理照片与旁白片段，数字人对着镜头讲述。

iv.

自动配乐

可选自动配乐：科技轻盈、明亮发布两档由云端签发档位，本机引擎按成片节奏合成，不依赖任何第三方曲库。不出镜也能配乐。

v.

双平台渲染

同一份内容，用本机的 Remotion 一次产出 B 站横版（16:9）和小红书竖版（9:16），各自适配排版，不用你二次剪辑。

vi.

字幕 + 封面

本机 ffmpeg 烧录中文字幕并生成两张对应尺寸的 PNG 封面。完整解码、音轨覆盖、字幕字形和尺寸 QA 通过后才交付，由你最终审核并决定是否发布。

本地三件套依赖

全部跑在你自己的机器上。

正式支持 macOS 与 Windows，不支持 Linux/WSL。没有云端媒体 worker，也没有远程渲染。云端只负责商业权限、创作决策与签名 Manifest；旁白文本会发送给所选 TTS 服务。install.sh / install.ps1 会检查本机缺少什么。

RENDER

Node + Remotion

用代码驱动的动画场景渲染双平台画面。安装 Node 20+ 后由 npm install 准备项目依赖。

VOICE

Python + edge-tts

音频文件在本机生成和保存；旁白文本由本机客户端发送给 Microsoft Edge 语音服务。也可自带 MiniMax key，把签名讲稿文本发送到自己的 MiniMax 账户。

MUX

ffmpeg（带 libass）

烧录中文字幕、合成成片。macOS 使用 ffmpeg-full；Windows 使用带 libass 的原生 ffmpeg build。最终都由 doctor 按能力验证。

怎么用

设计为 agent-friendly。

安装后的 Skill 驱动唯一控制流。Brief、10-credit Manifest 生成、完整签名讲稿分别是三次独立人工门禁；全部通过后才进入本地 TTS 和渲染。

常见问题

FAQ.

要钱吗？要注册账户吗？
需要有效的 AgentMesh360 月卡和通用 API Key。Lecturecast 使用月卡账户的共享 credits，无需另购独立 LectureCast 订阅；结构化选择和 Brief 不扣费，只有你明确批准生成 ProductionManifest 时才固定扣除 10 credits。
视频会上传到云端吗？
原始媒体不会上传。受限素材摘要、稳定选项 ID、Brief 和客户端能力进入云端 Director；旁白文本发送给所选 TTS 服务。原始媒体、本地路径、生成音频、字幕、渲染与成片留在本机。
配音用什么？能换更好的音色吗？
默认 Edge TTS 会把旁白文本发送到 Microsoft Edge 语音服务；MiniMax BYOK 会把签名讲稿文本发送到你自己的 MiniMax 账户。LectureCast 不会主动持久化 MINIMAX_API_KEY，建议用安全的进程环境注入；直接在 shell 中输入 export 可能进入历史记录。
视频是全自动生成的吗？有哪些人工门禁？
不是无人值守。你先批准 Creative Brief，再明确批准一次 10-credit Manifest 生成，最后逐段审阅并批准完整签名讲稿。签名内容生成后宿主 Agent 不得修改；不批准就停止，不会进入 TTS 或渲染。
需要装什么？
本地三件套：Node + Remotion（渲染）、Python + edge-tts（配音）、ffmpeg 带 libass（烧字幕）。macOS 的 install.sh 与 Windows 的 install.ps1 都会区分 CLI 安装成功和渲染器就绪；以 doctor 的能力检查为准。
支持哪些平台的成片？
标准交付是四个文件：B 站横版 MP4（1920×1080）、小红书竖版 MP4（1080×1920），以及两张对应尺寸的 PNG 封面。
Lecturecast 适合谁？和 CreatorCut 有什么区别？
Lecturecast 适合需要从一个主题生成知识讲解或课程视频的创作者、讲师和产品团队；AgentMesh-CreatorCut 则从已经录好的口播或产品录屏出发，完成智能后期。
公开客户端是开源的吗？
公开 CLI、本地执行工具与网站代码采用 Apache 2.0，位于 GitHub。完整产品仍只有一条商业路线：必须使用有效月卡、通用 API Key、共享 credits 和云端 Director，没有免账户路径。
